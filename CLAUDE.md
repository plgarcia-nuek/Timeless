# Timeless Design System — Claude Code operating manual

This file tells Claude Code **how to work** in this repo. For visual/design rules (theming, sizing, typography, naming, known design gaps), see `DESIGN.md` — read both before generating or editing any component, but don't duplicate DESIGN.md content here.

Source design system: **Timeless**, defined in Figma (`Timeless-DS Nuek`, file key `NbjzETzcEgTrofb3BoohYC`).

## Source of truth

- `tokens.json` in this folder is the canonical export of every color, spacing, radius, border-width and typography token from the Figma Foundations library. It is machine-generated — never hand-edit values in it, regenerate from Figma instead.
- `tokens.css` is the CSS custom-property mirror of `tokens.json`, ready to import. Use these variables (`var(--color-...)`, `var(--radius-...)`, etc.) instead of hardcoded hex/px values in any component you write or edit.
- If a value you need isn't in `tokens.json`, don't invent one — flag it and ask, or use the closest existing token. Check `DESIGN.md` → "Known design gaps" first; some missing tokens are documented, expected gaps, not something to guess around.

## Where to find components (Figma pages)

Pull components via Figma Dev Mode / MCP (`get_design_context`) against the live file, not from memory — several were recently rebuilt and an old version may still be cached in a prior conversation or screenshot.

- **Action**: `button/cta` (48 variants: Función × Jerarquía × Estado × Tamaño), `button/cta/mobile`, `accordion`, `chat`, `modal`, `cookies`, `optionSwitch` (⚠ pre-existing variant-property error in Figma, not yet fixed)
- **Data Display**: `dataTable` (5 dark variants + 1 light `Columnas=5, Tipo=No interacción`), `badge` (Estado: Success/Error/Warning/Info/Alternative), `tabOption`, `textTitlesBlock`
- **Feedback**: `popUpDialogue`, `loading`, `feedback`
- **Forms**: `form`, `fileUpload`, `stepsForm`, `datePicker`, `checkbox`, `toggle`, `dropdown`
- **Imagery**: `cardAvatar`, `card`, `mainCard`, `infoCard`, `imageText`, `heroSection`, plus **`featureCard`** (S/M/L), **`priceCard`** (S/M), **`mediaCard`** (M/L/XL), **`heroCard`** (XL/2XL)
- **Navigation**: `breadCrumb`, `barSearch`, `menuBar` (⚠ pre-existing variant-property error in Figma), `optionTab`, `Header`, `pagination`, `resultsSearch`, `navbarComercio`, `menubarGeneric`, `navGeneral`. No Footer or Sidemenu component exists in Figma — don't assume one does.

## Regenerating tokens.json / tokens.css

These files were generated by resolving every variable in the Foundations library (`semanticColor`, `semanticSpacing`, `semanticRadii`, `semanticBorder`, `semanticTypography`) across all their modes via the Figma MCP `use_figma` tool, then compiled to JSON/CSS. To refresh after a Figma change: re-run that resolution (don't hand-edit either file) and regenerate both together so they never drift from each other.

## React components (`../timeless-components`)

- Every CSS variable used in a component's `.module.css` must exist in `tokens.css` — grep-verify the exact variable name before using it (`grep -q -- "$name:" tokens.css`). This project has hit orphaned/renamed tokens before; don't assume a plausible-looking name resolves.
- Status of what's built lives in `timeless-components/README.md` — check it before regenerating a component that may already exist.
