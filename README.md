# Timeless
Sistema de Diseño de Nuek
Timeless es una colección de principios, reglas, componentes, patrones y decisiones que permiten diseñar productos digitales de manera consistente, escalable y accesible.

No pretende limitar la creatividad.

Pretende eliminar todas aquellas decisiones repetitivas que no aportan valor para que los equipos puedan concentrarse en resolver problemas reales.

Porque cada decisión que el sistema toma por nosotros es una decisión menos que el diseñador debe volver a cuestionarse.
